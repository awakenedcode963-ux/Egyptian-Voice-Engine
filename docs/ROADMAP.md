# Roadmap

- **M0 Foundation:** multi-voice architecture, profile schema, text normalizer, adapters, mastering, provenance, CI, consent and license docs.
- **M1 First voice:** obtain speaker authorization, record securely, run NAMAA in Colab GPU, create Noura acceptance set, native Cairo review and pronunciation tuning.
- **M2 Quality:** compare NAMAA/Habibi, measure latency/VRAM/repeatability, pin model and package revisions.
- **M3 Voice library:** add independently consented voices with separate profiles and acceptance evidence.
- **M4 Productization:** API, queue, authentication, tenant isolation, audit logs, secure storage, customer approvals and delivery.
