# Evaluation

Do not approve a voice after one demo. Run a fixed script suite and preserve scores per model and profile revision. Evaluate Cairo dialect, word endings, questions/emphasis/negation, agreement, numbers/prices/percentages/dates/phones, names, brands, medical terms, English loanwords, long-form consistency, clipping, noise and loudness.

Use the CSV scorecard with a native Egyptian Arabic reviewer familiar with Cairo colloquial speech. Critical numeric, negation or semantic errors block release.
